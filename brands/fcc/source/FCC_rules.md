# FCC Brand Rules
> These rules apply to all infographics and tables created for Flipkart Commerce Cloud (FCC). Every design must strictly follow these guidelines.
> Updated 2026-10-27 (v1.0.0): values measured from the 20 approved FCC infographics in `brands/fcc/past/`.

---

## 1. Frame / Canvas

| Property | Value |
|---|---|
| Width | 1920px |
| Height | Variable (fits content) |
| Background | `#FFFFFF` (white) |
| Content block | Centred, max ~1500px wide, minimum 80px padding, equal side margins |

---

## 2. Top Header Bar

Every infographic and table has a light blue header bar at the very top.

| Property | Value |
|---|---|
| Color | `#0164F0` at **10% opacity** |
| Height | 118px |
| Content | Title text only, centred, one line |

**Title text inside header bar:**
| Property | Value |
|---|---|
| Font | Inter |
| Weight | Medium (500) |
| Size | 48px |
| Color | `#0164F0` |
| Alignment | Center |

---

## 3. Color Palette

| Name | Hex | Usage |
|---|---|---|
| Primary Blue | `#0164F0` | Title, table header cells, filled pills, VS circle |
| Accent Blue | `#4E93F5` | Number markers, card outlines, card header bars, icons, connectors (most-used blue after primary) |
| Secondary Blue | `#2872ED` | Rare accent fills only |
| Light Blue (Tint) | `#E6F0FE` | Card and rail fills, label cells, takeaway box |
| Dark Text | `#383838` | All body text, labels, table content |
| White | `#FFFFFF` | Page background, text on blue fills |
| Light Gray | `#F2F2F2` | Neutral table cells, checklist cards |
| Outline Gray | `#888888` at ~50% | Neutral card outlines (occasional) |

---

## 4. Typography

**Font family: Inter (all elements)**

| Element | Weight | Size | Color |
|---|---|---|---|
| Title (header bar) | Medium (500) | 48px | `#0164F0` |
| Item / card heading | Medium (500) | ~32px | `#383838` or `#0164F0` |
| Body / description text | Regular (400) | ~30px | `#383838` |
| Pill / card header text | Medium (500) | ~30px | `#FFFFFF` |
| Table header text | Semi-Bold (600) | ~30px | `#FFFFFF` |
| Table body text | Regular (400) | 28–30px | `#383838` |
| Number markers (01, 02…) | Semi-Bold (600) | ~44px | `#4E93F5` |

**Rules:**
- Heading + subtext: heading Medium, subtext Regular
- Text color is `#383838` by default; never light grey text
- Text on blue fills (`#0164F0`, `#4E93F5`) is `#FFFFFF`
- Text on `#E6F0FE` is `#383838` or `#0164F0`
- Sentence case; never all caps
- Each item: short heading plus one or two lines at most

## 5. Infographic Rules

### Layout
- Frame: 1920px wide, height adjusts to content
- Top header bar always present (see Section 2)
- White page background, flat design: no shadows, gradients or emoji
- Content is a centred block, not full bleed, with generous whitespace

### Cards & Shapes
- Corner radius: ~20px for cards and pills, ~15px for small cells
- Card styles: `#E6F0FE` fill, or white with a 3px `#4E93F5` outline
- Card header: pill or bar in `#0164F0` / `#4E93F5` with white text
- Optional takeaway box at the bottom: one sentence, `#E6F0FE` fill, `#4E93F5` outline, centred text

### Markers, Icons & Connectors
- Number markers: two-digit (01, 02…) in `#4E93F5` inside a 3px circle or hexagon; or a check mark
- Icons: line icons from any source, restyled to `#4E93F5` with one consistent stroke; optional circle, square-tint or hexagon container
- Icon size scales with the infographic (about 0.6 × the height of the item it sits in), not a fixed size
- Connectors: thin `#4E93F5` lines, dashed or solid, aligned to marker centres

### Layout Variation Rule — IMPORTANT
- **Never repeat the same layout family consecutively** (the registry tracks the last one)
- Layout families used in approved FCC work:
  1. **Vertical list** — icon tiles, circle/hexagon numbers, or numbers in a tinted side rail, with connector line
  2. **Horizontal timeline** — arrow markers, or hexagon numbers with labels alternating above/below
  3. **S-curve steps** — numbered circles on a wave, labels alternating above/below
  4. **Hexagon zig-zag row** — hexagon icons with labels above/below
  5. **Central spine** — vertical line with icon items on both sides
  6. **Comparison cards** — pill header, outlined, VS circle, or divider line between two cards
  7. **Cell table** — comparison or definition table (see Section 6)
  8. **Card list** — stacked cards with check marks or numbers
- Also allowed (not yet used): three-column grid, hub and spoke, pyramid, before vs after, stat callout grid

---

## 6. Table Rules

### Structure
- Frame: 1920px wide, height fits rows
- Top header bar always present (see Section 2)
- Built from **separate rounded cells with even gaps**, not full-width rows with divider lines

### Colors
| Part | Background | Text Color | Text Weight |
|---|---|---|---|
| Column headers (row 1) | `#0164F0` | `#FFFFFF` | Semi-Bold (600) |
| Row label column | `#E6F0FE` or `#F2F2F2` | `#383838` | Semi-Bold (600) or Regular |
| Data cells | `#F2F2F2` | `#383838` | Regular (400) |

### Layout
- 2 to 4 columns (label column + 1–3 data columns)
- Cell text centred, cell radius ~4–15px
- No borders, no alternating stripes

---

## 7. What Never Changes Across Designs

- Font: always **Inter**
- Frame width: always **1920px**
- Top header bar: always present, `#0164F0` at 10% opacity, 118px
- Title: `#0164F0`, 48px, Inter Medium, centred
- Primary blue `#0164F0`, accent blue `#4E93F5`
- Body text: always `#383838`
- Flat: no shadows, gradients or emoji

---

## 8. What Can Vary (Infographics Only)

- Layout family (must rotate, never repeat consecutively)
- Number of items, columns or rows
- Marker type: numbers, icons, check marks; circle vs hexagon
- Card style: tint fill vs white with outline
- Height of the frame
- Optional takeaway box at the bottom
